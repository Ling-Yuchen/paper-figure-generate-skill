# 绘图说明模板

绘制前填写决定比例和科学内容所必需的字段，其余可在绘制过程中补充。默认自行提出合理参数，不要求用户逐项填写。此模板用于生成每张图的 `figure-brief.md`。

- 图名、类型与一句话主旨：

- 标签语言与可移到图注的解释：
- 未知信息、假设及是否影响科学含义：

### 具体比例示例

三阶段横向方法图，可采用以下一种布局；其中 16:9 只演示空间计算，不是默认论文比例：

- 画布 `1200 × 675`，比例 `16:9`，四边留白 `40`。
- 内容宽度 `1120`；模块宽度依次为 `260 / 420 / 260`，两个间隔均为 `90`。
- 水平方向校验：`40 + 260 + 90 + 420 + 90 + 260 + 40 = 1200`。
- 模块分别从 `x = 40 / 390 / 900` 开始；共同 `y = 145`、高度 `380`。
- 顶部 `y = 40…110` 可安排面板标题，底部 `y = 565…635` 可安排必要图例。
- 容器内边距 `24`；主标签 `26`，辅助标签 `22`，主图标 `48 × 48`，连线宽度 `2.5`。
- `90` 单位的模块间隔包含连接线与箭头所需空间；实际路径避开标签。

此示例只演示可计算的空间分配，不要求其他图沿用。字号必须随最终印刷尺寸复核：在宽 `180 mm`、`viewBox` 宽 `1200` 的图中，`26` 单位约为 `11.1 pt`；缩到 `90 mm` 后约为 `5.5 pt`，需要重新调整字号、内容或布局。

## 视觉方向与做工（新绘或视觉重绘时填写）

按 [视觉层级与细节设计](visual-craft.md) 将方向落实为决策：

- 参考图或当前图的三条具体观察，哪些保留、哪些改进：
- 第一视觉入口、随后阅读路径及应弱化的外围部分：
- 颜色、线宽、字体、间距的角色参数及数值：
- 主区 / 标题带 / 子区 / 节点的底色、边框色与物理线宽；相邻层级如何区分：
- 子分区的所属父区、包含节点、标题位置、内边距与跨框端口：
- 核心机制采用何种内部图形；依据与示意范围：
- 图标可见尺寸、光学居中与图文间距处理：
- 每种元素框的内容区、标题栏尺寸及对称内边距；单元素或图文组合的边界测量方式、双轴中心偏差与修正结果：
- 是否比较变体；改变的设计假设与不变的科学内容：
- 同尺度前后对照及五维评审中的具体修复：
