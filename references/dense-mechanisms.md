# 高密度复杂图版设计

用于在有限论文版面内组织较多实体、关系或局部细节，以及修复空白过多、结构松散、重点不突出的问题。适用于系统框架、方法机制、实验流程、概念关系和综合图版；不预设学科、组件类型或固定拓扑。信息密度由可读且必要的内容决定，与是否出现某类专业图形无关。

## 分开处理内容来源与视觉参考

论文、数据、方法描述和用户明确指定的内容决定**画什么**；仅作为效果参考的图片决定**怎样组织和呈现**。在绘图说明中分别记录这两类来源。参考图只有被用户明确指定为重绘对象或内容来源时，才提取其科学实体与关系；不能因为看到了某种结构，就将其加入当前方法。

从效果参考提取可迁移的设计变量：有效画幅比例、主辅区面积关系、局部密度、对齐节奏、图文比例、底色与边框层级、标签和连线的清晰程度。外围截图留白不计入有效图版。参考的配色数量、分区数量、排列方向和拓扑均不是默认模板；颜色角色与分区布局由当前内容重新确定。

先确定本图要让读者完成的阅读任务：识别组成、追踪过程、比较差异，或理解内部机制。所需展开程度据此选择；系统组成图不必补上计算细节，机制图则应展开源材料中解释机制所需的关系。视觉上更复杂不等于表达更完整。

## 按内容预算空间

先列出每个区域必须传递的实体、关系、标签与必要细节，区分核心信息、辅助信息和可交给图注的解释。一个可解释单元可以是实体、操作、状态、证据或局部关系；重复装饰与背景面积不计为信息量。

先估计各局部组合的紧凑包围盒，再组织为规整图版：

- 区域面积容纳内容、文字、内边距与连接通道；按实际负载分配宽高，同级对齐不要求等宽或等面积。
- 核心关系在其发生位置展开，辅助内容沿阅读路径邻接安排；不要把所有节点都做成统一尺寸的大卡片。
- 先保证最终物理字号和必要间距，再确定画幅；不能先铺满固定大画布，随后用放大图标或拉长连线填空。
- 单个元素或图文组合按 [组合内容居中](visual-craft.md#组合内容居中) 在所属内容区双轴居中。主体网格、标题区与路由空间事先划定，紧凑化不取消居中与留白要求。

下列是按**关系形态**选择的局部组织方式，可以组合使用，不是每张图都要包含的模块：

| 已确认的关系 | 可选组织方式 | 选择依据 |
| --- | --- | --- |
| 顺序或依赖 | 紧凑行列、分段管线 | 方向明确，避免不必要的折返 |
| 并列或比较 | 相邻区、共同基线或对应列 | 对应项易比较，差异清晰 |
| 包含或归属 | 嵌套分区、共享底板或分隔带 | 层级可辨，避免重复套框 |
| 多对一或一对多 | 局部汇聚、分支布局 | 汇合点和分支身份可追踪 |
| 共享、交互或反馈 | 邻接接口、局部回路、外围通道或具名引用 | 连线长度与歧义之间取舍 |
| 重复或周期结构 | 对齐小单元、重复行列或明确省略 | 仅复用真正相同的结构，保留变化项 |

## 提高有效密度

逐区检查空白是否用于标签保护、分组、路由或阅读停顿。没有用途的大块空白，优先通过收紧节点、缩短间隔、重分配宽高或重新拼版修复；不凭空增加内容。尤其检查高大的短标签框、内容较少的等高分区、过厚标题区和长连线两侧。

建议的调整顺序是：移出重复解释 → 选择更紧凑的内容表达 → 收紧局部组合 → 共享对齐线 → 缩短连接路径 → 调整分区与画幅。每步保持科学关系与读者所需细节。信息量本身较少时，应缩小画幅或接受合理留白，不追求参考图的视觉繁复程度。

背景、边框和子区的层次按 [底色、边框与子分区](visual-craft.md#底色边框与子分区) 表达归属，不以更多套框增加层级感。密集区域尤其需要区分容器边界、内容轮廓与连接线的视觉重量。

不设统一留白百分比、节点数或像素墨色率门槛。检查的是单位版面承载的必要信息及其可读性；密度提高后，主次和路径应更容易辨认。

## 按语义选择局部图形

先确认对象的含义，再选择图标、标签、几何结构或数据图。几何外形与内部细节都可能暗示科学含义，不能作为通用装饰。例如，仅在内容确有对应含义时才使用时间轴、设备剖面、关系网络或矩阵；不能从效果参考直接移植这些图形。

常见实体可用项目图标辅助识别；关键关系使用真实SVG图元与连接表达；有准确数据的局部图由数据生成。重复绘图函数的参数围绕位置、尺度、标签、语义角色和接口设计，不把某个示例的组件名称、数量或排列写成默认值。

细节服务于识别和解释：图标保持可见尺度一致，相关标签就近归组，专业符号在图内或图注中定义。示意图形明确其示意性质；无依据的维度、数量、结果或关系不添加。需要解释的机制不能只用一个图标替代，但也不要求所有对象都展开内部结构。

## 密集关系的布线

先组织局部关系，再处理跨区连接。端口、标签、箭头与转角均占用真实空间；内部连线也纳入关系记录与碰撞检查。不同关系用明确语义区分，箭头不能自动代表所有关联。

同一实体被多处使用时，可选择共享实例或具名引用，记录身份和使用点；独立实体不能为减少线条而合并。引用只在读者能明确追溯时使用，不能掩盖必要的交互过程。需要显式展示路径时，优先调整邻接关系或通道。

跨区线路避开标题、标签和其他实体；新增底板或调整内容组合后复查线路连续性。既无法清楚布线又无法保持可读性时，拆分为关联面板或总体图与细节图，并保留明确的对应关系。

## 验收与通用性验证

在目标栏宽下查看整图、局部和灰度预览，核对：

1. 全部实体与关系来自当前任务，效果参考没有引入额外内容或固定结构。
2. 展开程度符合阅读任务，核心信息明确，各区域面积与其内容相称。
3. 空白有用途，图文组合居中；文字、图形、边框和连接没有非预期冲突。
4. 标签和关系可追踪，符号、重复内容与省略范围能被理解。
5. 最终尺寸下关键内容可读；必要时分图，不能靠大幅缩字维持单图。

维护skill时，按本次修改影响的能力选择不同内容与关系形态的用例，检查相同设计规则能否适用，而不要求不同题材生成相同骨架。例如并列比较与闭环系统可分别验证对齐组织与反馈布线；这只是选例思路，不是强制测试内容清单。检查规则是否会诱导加入源材料不存在的组件，比替换示例术语更能检验通用性。

[验证文档](validation.md#高密度复杂图版实绘) 中的固定用例用于可复现回归，其学科内容、节点数量和布局参数仅属于测试。一个用例通过只证明实际覆盖的能力，不能视为通用绘图模板或全部领域的验证。修改影响绘图行为时，实际渲染受影响用例并记录覆盖范围；保留已有基础测试。
